# 📚 ExamMate

**Telegram Mini App для подготовки к ЕГЭ, ОГЭ и IELTS по английскому языку**

Тренировка в формате реального экзамена, мгновенная проверка ответов
и оценка письменных работ по официальным критериям.

## О проекте

ExamMate открывается прямо внутри Telegram — без установки из магазинов приложений —
и работает как полноценное мобильное приложение: экраны с заданиями, кнопки, графики прогресса.

Английский выбран не случайно: у ЕГЭ, ОГЭ и IELTS совпадают разделы
(чтение, аудирование, грамматика, письмо, говорение), поэтому одна система заданий,
проверки и статистики обслуживает все три экзамена — различаются только форматы и критерии оценивания.

> Учебный проект. Задания составлены самостоятельно по открытым демоверсиям
> и спецификациям ФИПИ и официальным материалам IELTS.

## Возможности

| | Функция | Описание |
|---|---|---|
| 🎯 | **Входной тест** | 15–20 заданий, определяет уровень и слабые разделы |
| 📝 | **Тренировка по разделам** | Задания в формате экзамена, мгновенная проверка, объяснение ошибок |
| 🎧 | **Аудирование** | Запись + вопросы, есть режим «как на экзамене» |
| ✍️ | **Проверка эссе** | Балл по каждому официальному критерию, разбор ошибок |
| 🎙 | **Устная часть** | Голосовой ответ расшифровывается и оценивается |
| ⏱ | **Пробный экзамен** | Полный вариант с таймером и переводом баллов |
| 📖 | **Личный словарь** | Слова из ошибок + интервальное повторение |
| 📊 | **Статистика и план** | Динамика по разделам, план подготовки до даты экзамена |

## Технологии

**Серверная часть** — Python 3.12, aiogram 3, SQLAlchemy, Alembic
**База данных** — PostgreSQL, Redis (состояния и кэш)
**Интерфейс** — Telegram Mini Apps: HTML, CSS, JavaScript
**Проверка работ** — API языковой модели + распознавание речи
**Инфраструктура** — Docker, VPS, HTTPS

---

## Структура проекта

```
exammate/
├── bot/              # серверная часть на aiogram
│   ├── handlers/     # обработчики команд и запросов
│   ├── keyboards/    # клавиатуры
│   ├── states/       # сценарии диалогов (FSM)
│   └── middlewares/  # БД, антиспам, логирование
├── webapp/           # интерфейс Mini App
├── services/         # проверка ответов, оценка эссе, статистика
├── db/               # модели и миграции
├── content/          # задания, аудио, критерии оценивания
└── tests/
```

## Запуск

```bash
git clone https://github.com/enjoyfauner-cloud/exammate.git
cd exammate
cp .env.example .env        # укажите токен бота и ключ API
docker compose up -d
```
